# CDI Field Safety Management Tool · v223

This folder is the complete multi-file website. Keep every folder and filename together.

## Open it locally

For a quick visual check, open `index.html`. Some browsers block PDF viewing or live weather when a site is opened directly from a device, so GitHub Pages is the recommended test.

## Publish with GitHub Pages

1. Open the GitHub repository used for the current safety website.
2. Upload **all files and folders inside this package** to the repository root. Do not upload only the ZIP.
3. Keep these folders unchanged: `assets`, `css`, `data`, `forms`, and `js`.
4. In GitHub, open **Settings → Pages**.
5. Select **Deploy from a branch**, choose the site branch and `/ (root)`, then save.
6. Open the GitHub Pages link after deployment finishes and confirm the badge reads `v223`.

## Important checks after upload

- Create a test PTP and confirm all three official CDI pages are visible in the preview.
- Save the test PTP and confirm the page backgrounds, typed information, and X marks are all present.
- Open Forms and test the Safety Manual, Sign In Sheet, MEWP checklist, and Z87 Visor Agreement.
- Confirm the weather header and calendar update from the National Weather Service.

The official CDI PTP page artwork is stored in `assets` and was not redesigned.

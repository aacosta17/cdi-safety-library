How the policy engine works

The app uses layers. CDI company requirements always apply. A project-specific rule set can be added on top. If a project has a special form, the same PTP answers can later be mapped into that project's template.

Layer 1 — CDI Company Standard

Safety manual, PTP/JSA/JHA process, PPE, fall protection, ladders, aerial lifts, electrical safety, LOTO, hazard communication, material handling and more.

Layer 2 — Project / GC Oversight

Placeholder in Version 1. Upload a project manual and template, then its requirements can be added here.

Layer 3 — Task Conditions

The worker's answers determine which hazards and controls are suggested.
